## Witness representation and consumed input

Only these inputs are required:

```text
scenario.theoryParameters.maxLongitudinalBrake = B > 0
scenario.theoryParameters.maxLongitudinalAccel = C > 0
z0.gR,z0.cR,z0.gF,z0.cF,z0.gT,z0.cT
T >= 0
witness.times
witness.ax
```

No y, w, A, Road, W, overshoot, vehicle snapshots or full Scenario validation
is consumed. Extra fields are ignored, including any user-declared eta/zeta;
those values are never trusted or matched as target moments. Consumed scalar
values must be finite real numeric scalars convertible to double. Logical,
complex, missing or nonscalar consumed scalar values are malformed input.
Negative initial gaps are valid data with an unsafe-prefix consequence.

For N positive-duration segments:

```text
times = [t0,...,tN], length N+1
ax    = [a1,...,aN], length N
t0 == 0, tN == T, times strictly increasing
ax(t) = ai on [t(i-1),t(i))
```

Both vectors must be finite, real and numeric. Row/column input is accepted
and normalized to double columns in the certificate. Nonuniform partitions
are supported. Repeated, decreasing, missing or mismatched endpoints are
malformed; exact equality is used without partition tolerance. The control's
value at isolated switching/end times does not change the trajectory.

For T=0, the only permitted representation is scalar `times=0` and an empty
numeric ax vector (`ax=[]`, normalized to 0-by-1). N=0, mu is empty, moments
are zero, segments is a 0-by-1 struct array, terminal equals the initial state,
and minima occur at time zero. Safety is exactly the three initial gap checks.

Well-formed finite controls outside `[-B,C]` are **inadmissible witnesses**,
not malformed data. They are propagated for audit but have
`control.withinBounds=false`, `validWitness=false`, and reason
`CONTROL_OUT_OF_BOUNDS`. Controls are never clipped.

## Exact segment propagation and continuous-time minima

For a segment of duration h with acceleration a, use local time tau in [0,h]:

```text
R: cR(tau)=cR0-a*tau,  gR(tau)=gR0-cR0*tau+a*tau^2/2
T: cT(tau)=cT0-a*tau,  gT(tau)=gT0-cT0*tau+a*tau^2/2
F: cF(tau)=cF0+a*tau,  gF(tau)=gF0-cF0*tau-a*tau^2/2
```

The values at tau=h are passed directly to the next segment. No fixed-step
engine, double-integrator primitive, numerical integration or time sampling
participates in the authoritative safety check.

For the generic quadratic `q(tau)=g-c*tau+curvature*tau^2/2`:

1. Evaluate tau=0 and tau=h.
2. Only if curvature>0, compute `tauStar=c/curvature`.
3. If `0<tauStar<h`, also evaluate that interior minimum.
4. Select the smallest candidate; exact ties select the earliest local time.

Thus R/T have a possible interior minimum only for a>0, at cR/a or cT/a.
F has one only for a<0, at -cF/a. For zero/negative curvature, endpoints
suffice. A stationary point exactly at a segment endpoint is already covered.

Global minima include the initial gaps and every segment minimum. Exact
computed ties retain the earliest global time. Each segment records its
start/end state, local minimum values and local minimizing tau values; global
times add t0 to the local tau.

## Closed safety and certificate truth

```text
safeR = minimumR >= 0
safeF = minimumF >= 0
safeT = minimumT >= 0
withinBounds = all(-B <= ax & ax <= C)
validWitness = withinBounds && safeR && safeF && safeT
```

Safety and control bounds use **no epsilon or tolerance**. Exact contact is
safe. A tiny negative minimum remains unsafe even if smaller than an internal
arithmetic-audit tolerance. Neither gap values nor controls are snapped.

The two statuses are `SAFE_WITNESS` and `UNSAFE_WITNESS`. Reasons, in priority
order, are `CONTROL_OUT_OF_BOUNDS`, `INITIAL_GAP_UNSAFE`, `PREFIX_GAP_UNSAFE`,
or `WHOLE_PREFIX_SAFE`. A negative initial gap fails safety at t=0 for every
T, even when that particular control later makes the gap positive.

For the reduced model, a valid supplied piecewise-constant control is also
measurable; a successful analytic certificate supplies a constructive witness
for the original continuous-control existence definition. In particular its
actual moments belong to the true M_x_safe(T).

An unsafe supplied candidate proves **only that this candidate fails**. It
does not say M_x_safe(T) is empty, fixed-T preservation is impossible, or
tauDual<T. There is no INFEASIBLE or UNRESOLVED status in this verifier.

## Actual moments and raw-lens consistency

With K=B+C, each segment has `mu_i=(a_i+B)/K`. For admissible acceleration,
0<=mu_i<=1. The verifier computes the candidate's actual moments:

```text
eta  = sum(mu_i*h_i)
zeta = sum(mu_i*h_i*(T-(t0_i+t1_i)/2))
```

The implementation evaluates the weight as `T-t0_i-h_i/2`, an algebraically
equivalent form that avoids summing two large endpoint times. No extra
declared moments or moment-matching constraint is accepted.

The raw lens is audited via the four margins:

```text
[eta; T-eta; zeta-eta^2/2; T*eta-eta^2/2-zeta]
```

`arithmeticAudit.rawMomentLensExact` is the literal nonnegative-margin check.
`moments.rawMomentLensSatisfied` is the internal consistency check allowing
only the documented floating-evaluation roundoff below. Original margins
are preserved; they are not clipped. This diagnostic is not whole-prefix
safety or a safe-set membership oracle.

A materially inconsistent raw lens for an admissible control raises
`AVLC:LongitudinalWitnessArithmeticFailure`. For an out-of-bound control,
the raw lens may legitimately fail; its false flag is retained without
mistaking inadmissibility for an arithmetic defect.

## Independent terminal moment check

In order `(gR,cR,gF,cF,gT,cT)`, compare recursive propagation with

```text
cF(T) = cF0-B*T+K*eta
cR(T) = cR0+B*T-K*eta
cT(T) = cT0+B*T-K*eta
gF(T) = gF0-cF0*T+B*T^2/2-K*zeta
gR(T) = gR0-cR0*T-B*T^2/2+K*zeta
gT(T) = gT0-cT0*T-B*T^2/2+K*zeta
```

Both the independently computed terminal state and residuals are exposed.
They must agree within the arithmetic allowance, or the function raises an
arithmetic failure rather than returning a misleading safety certificate.

### Arithmetic consistency is not theorem tolerance

The fixed consistency factor is `f=64*(N+1)`. Each terminal coordinate uses
`tolerance_j=f*eps(scale_j)`, with scale_j the maximum of:

- 1, the absolute recursive result and the absolute moment result;
- the initial absolute coordinate plus the sum of absolute recursive
  increments (absolute c*h and a*h^2/2 for gaps; absolute a*h for rates);
- the absolute initial coordinate plus the absolute terms in the independent
  moment formula.

For the first two raw-lens margins use `f*eps(etaScale)`, where
`etaScale=max(1,abs(T),sum(abs(mu.*h)))`. For the last two use
`f*eps(zetaScale)`, where zetaScale is the maximum of 1, abs(zeta), the sum
of absolute zeta contributions, abs(eta^2/2), and abs(T*eta).

These scale-aware allowances audit two algebraically equivalent double
evaluations; they are not a new physical margin and do not establish interval
arithmetic guarantees. They never enter `minimum>=0` or `-B<=a<=C`.
"Exact" means analytic segment propagation, integration and extrema with no
time-discretization or search approximation; ordinary MATLAB double roundoff
still applies.

## Exact output schema

```text
certificate
  status,validWitness,reason
  control: times,ax,mu,withinBounds
  moments: eta,zeta,rawMomentLensSatisfied
  gaps: minimumR,minimumF,minimumT,
        timeOfMinimumR,timeOfMinimumF,timeOfMinimumT,safeR,safeF,safeT
  terminal: gR,cR,gF,cF,gT,cT
  segments (N-by-1 struct array):
    t0,t1,ax,start,terminal,
    localMinR,localMinF,localMinT,localMinTauR,localMinTauF,localMinTauT
  arithmeticAudit:
    coordinateOrder,terminalFromMoments,terminalResidual,terminalTolerance,
    terminalConsistent,rawMomentLensExact,rawMomentLensMargins,
    rawMomentLensTolerance,consistencyFactor
```

`start` and segment `terminal` contain the same six longitudinal fields.
Numeric fields are doubles, flags logical, status/reason string scalars.
Residual/tolerance/lens vectors are columns; coordinateOrder documents the
six terminal-coordinate positions. No input is mutated and no class is added.

## Error policy

`AVLC:InvalidLongitudinalWitnessInput` covers malformed consumed values,
missing fields, invalid partition/dimensions, T<0, or B/C<=0. Negative gaps
and finite out-of-bound accelerations are witness failures, not input errors.
Unrepresentable/nonfinite derived arithmetic or a failed terminal/raw-lens
consistency audit uses `AVLC:LongitudinalWitnessArithmeticFailure`. The
verifier does not silently classify overflow as unsafe or clip it away.

## Hand-calculated anchors

Take B=C=2, T=2, initial `(gR,cR,gF,cF,gT,cT)=(10,1,20,-1,15,2)`.

| Constant ax | mu | eta | zeta | Terminal `(gR,cR,gF,cF,gT,cT)` |
| --- | --- | --- | --- | --- |
| -2 | 0 | 0 | 0 | (4,5,26,-5,7,6) |
| 0 | 0.5 | 1 | 1 | (8,1,22,-1,11,2) |
| 2 | 1 | 2 | 2 | (12,-3,18,3,15,-2) |

For the nonuniform three-segment witness `times=[0,0.5,1.5,2]`,
`ax=[-2,2,0]`, mu is `(0,1,0.5)`. Hence eta=`1+0.25=1.25` and
zeta=`1+0.5*0.5*0.25=1.0625`. Integrated acceleration is -1+2+0=1;
X(T)=`4*1.0625-2*2^2/2=0.25`. Terminal state is
`(8.25,0,21.75,0,11.25,1)`.

Recursive segment terminals are `(9.25,2,20.75,-2,13.75,3)`, then
`(8.25,0,21.75,0,11.75,1)`, then the final tuple above. The global minima
are R=8.25 at 1.5, F=20 at 0, T=11.25 at 2.

For R or T, use a=2,h=2,g0=0.5,c0=2. For F use a=-2 with the same gap/rate.
In all three cases both endpoints are 0.5, but the interior minimum is -0.5
at tau=1. All three must be UNSAFE_WITNESS. Replacing g0 with 1 makes an
exact safe contact; binary perturbations of g0 preserve the corresponding
negative/zero/positive safety decision without a tolerance.
