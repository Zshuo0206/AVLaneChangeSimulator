## Closed global base and capability sets

Use the frozen reduced state `(y,w,gR,cR,gF,cF,gT,cT)` and constants
`A=maxLateralAccel`, `B=maxLongitudinalBrake`, `C=maxLongitudinalAccel`,
`delta=targetOvershoot`. `W=road.targetLaneCenterY-road.originalLaneCenterY`.

```text
X_base = { y>=0, w>=0, gR>=0, gF>=0, gT>=0 }
K_pres = X_base intersect K_O intersect K_T
```

All comparisons are exact non-strict comparisons. There is no epsilon,
boundary snapping or sign tolerance. An equality belongs to the closed set.

### Frozen one-sided viability function

For `a>0,H>=0`, the private local helper implements

```text
Psi_a(c,H) = max_{0<=s<=H} (c*s-a*s^2/2)
          = 0                    if c<=0
          = c^2/(2*a)            if 0<c<=a*H
          = c*H-a*H^2/2          if c>a*H
```

This includes `c=0`, `c=a*H` and `H=0`. It creates no opportunity clock or
public helper API. Nonclosing and stopping-distance-safe situations need no
artificial finite approximation to infinite opportunity.

### Closed abort membership

On `y>=0,w>=0`, independently evaluate the Part-VI representation:

```text
thetaO = (w+sqrt(2*w^2+4*A*y))/A
psiR   = Psi_C(cR,thetaO)
psiF   = Psi_B(cF,thetaO)
FRO    = gR-psiR
FFO    = gF-psiF
FGO    = gR+gF-(cR+cF)*thetaO
abort.inSet = FRO>=0 && FFO>=0 && FGO>=0
```

`abort.domainDefined` means `y>=0 && w>=0`. Outside this domain, `inSet` is
false and all six numeric abort fields are NaN. No theory-domain exception
is raised for negative y/w. Negative gaps are evaluated normally and fail
their corresponding one-sided margin; they are not malformed data.

No `min(TRsafe,TFsafe,TG)`, finite frontier, reserve or other capability
evaluator participates in this truth predicate.

### Closed completion membership

```text
DT = W-y
D0 = w^2/(2*A)
Dphys = D0-delta
physicalRecoverable = w>=0 && DT>=Dphys
```

Only when physically recoverable:

```text
thetaT = (sqrt(2*w^2+4*A*DT)-w)/A    if DT>=D0
thetaT = (w+sqrt(2*w^2-4*A*DT))/A    if Dphys<=DT<D0
psiT   = Psi_C(cT,thetaT)
FTC    = gT-psiT
completion.inSet = FTC>=0
```

At `DT==D0`, the implementation explicitly evaluates the common value `w/A`
and labels the branch `NON_OVERSHOOT`. This is the exact switch identity,
not a tolerance-based special region. The other valid time branch is
`OVERSHOOT_RETURN`. `Dphys` equality is included.

Outside physical recoverability, `thetaT/psiT/FTC` are NaN and membership is
false, even if a target opportunity would be infinite. `timeBranch` is
`PHYSICALLY_UNRECOVERABLE`, or `OUTSIDE_PROGRESSIVE_DOMAIN` when `w<0`.
This describes the execution-time formula, not an upper-frontier mechanism.
`DT/D0/Dphys` remain diagnostic scalar quantities on negative inputs when
representable. The completion physical predicate can be evaluated at a
negative y; the base and abort predicates still exclude that state from
preservation. No pre-decision claim outside the Master's domain is inferred
from an individual component flag.

### Closed preservation membership and exact output schema

```text
membership
  base
    yNonnegative,wNonnegative,gRNonnegative,gFNonnegative,gTNonnegative,inSet
  abort
    domainDefined,thetaO,psiR,psiF,FRO,FFO,FGO,inSet
  completion
    physicalRecoverable,DT,D0,Dphys,thetaT,timeBranch,psiT,FTC,inSet
  preservation
    inSet = base.inSet && abort.inSet && completion.inSet
```

Flags are logical scalars, numeric outputs are doubles, and `timeBranch` is
a string scalar. No top-level alias or `dualCapable` field is added.

## Global objects versus finite reserves; reuse boundaries

Closed capability sets are global mathematical objects. `YO/YTin/YTout` and
`rO/lT/rT` are finite-chart coordinates and are not membership prerequisites.
The new evaluator covers w=0, finite/infinite-opportunity transitions and
nonsmooth boundaries without querying branch active sets.

P0.2.7 remains unchanged and is a **test-only cross-validation reference**
on the common supported domain `y,w>=0`. Production P0.3.1 does not call it
or copy its booleans. The independently implemented execution-time formulas
here are required by the approved P0.3.1 closed-representation contract; they
do not modify the frozen evaluator. P0.2.8 diagnostics and P0.2.9 local GF2
are also not dependencies. Their finite-chart or local-domain restrictions
do not restrict this global pointwise predicate.

`preservation.inSet=true` means the current state belongs to the closed
preservation set. It does not establish existence of a positive-duration
shared preserving prefix, fixed-T feasibility, a horizon or a chosen control.

## Exact progressive lateral endpoint map

Only A, `z0.y`, `z0.w`, T and rho are consumed. With
`alpha=(A+ay)/(2*A)`, rho is `A*integral(alpha)`, a positive lateral
acceleration allocation measured in velocity units. It is not position,
a longitudinal moment or a sampled control input.

The theorem domain is `T>=0,w0>=0`. A finite negative y0 is allowed as a
translation of the lateral system; this function does not impose global
state membership or any longitudinal safety requirement.

```text
rhoLower = max(0,(A*T-w0)/2)
rhoUpper = A*T
rhoAdmissible = rho>=rhoLower && rho<=rhoUpper
sigma = A*T-rho
wT = w0+2*rho-A*T
yBarT = y0+w0*T+2*T*rho-A*T^2/2-rho^2/A
betaMax = (2/A)*(rho*sigma-max(sigma-w0,0)^2/2)
yMinus = yBarT-betaMax
yPlus = yBarT
```

The returned interval `[yMinus,yPlus]` is **EXACT + EXPLICIT**. P5b-L1 proves
all intermediate beta values attainable, so this is not an outer bound.
No control path, witness, beta search or trajectory simulation is required.
The implementation evaluates wT algebraically as
`2*(rho-rhoLower)` when `A*T>w0`, and `(w0-A*T)+2*rho` otherwise. This is the
same formula and retains exactly zero at an active lower allocation edge
without clipping or tolerance.

### Domain/status and output schema

```text
reach
  defined,reason,T
  rhoLower,rhoUpper,rhoAdmissible
  sigma,wT,yBarT,betaMax,yMinus,yPlus
```

- `w0<0`: `defined=false`, reason `OUTSIDE_PROGRESSIVE_DOMAIN`, rho bounds
  NaN, `rhoAdmissible=false`, and all six endpoint fields NaN.
- `w0>=0` with rho outside the closed interval: `defined=true`, bounds
  defined, `rhoAdmissible=false`, reason `RHO_OUTSIDE_INTERVAL`, all six
  endpoint fields NaN. An invalid allocation is not an input exception.
- Admissible rho: reason `EXACT_REACHABLE_INTERVAL` and all endpoints defined.
- `T=0`: only rho=0 is admissible, sigma=0, wT=w0, betaMax=0 and
  `yMinus=yPlus=yBarT=y0`. Other finite rho values return an inadmissible result.
- `rho=rhoUpper`: sigma=betaMax=0 and the interval is a singleton.
- `rho=rhoLower` with `A*T>w0`: wT=0.

When `sigma<=w0`, betaMax is `2*rho*sigma/A`. When `sigma>w0`, subtract
`(sigma-w0)^2/A`. Both cases and their exact switching equality are tested.
No tolerance changes a boundary classification.

All use A=2. Output columns are in the public field order.

| Case | y0 | w0 | T | rho |

| 1: sigma<w0 | 1 | 2 | 1 | 1.5 |
| 2: zero initial/terminal w | 1 | 0 | 2 | 2 |
| 3: sigma>w0 | 1 | 1 | 2 | 2 |

| Case | rhoLower | rhoUpper | sigma | wT | yBarT | betaMax | yMinus | yPlus |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 0 | 2 | 0.5 | 3 | 3.875 | 0.75 | 3.125 | 3.875 |
| 2 | 2 | 4 | 2 | 0 | 3 | 2 | 1 | 3 |
| 3 | 1.5 | 4 | 2 | 1 | 5 | 3.5 | 1.5 | 5 |

For case 1, yBarT=`1+2+3-1-1.125=3.875` and
betaMax=`1.5*0.5=0.75`. For case 2, yBarT=`1+8-4-2=3` and
betaMax=`2*2-2^2/2=2`. For case 3, yBarT=`1+2+8-4-2=5` and
betaMax=`2*2-(2-1)^2/2=3.5`. Subtracting betaMax gives each lower endpoint.
These are hand anchors, not numerical simulation checks.

## Consumed-input validation and Inf/NaN policy

Both functions accept scalar structs and extra unused fields. Only consumed
fields are validated. There is no full Scenario/vehicle validation call.

| Evaluator | Required consumed fields |
| --- | --- |
| Global membership | Four theory constants A/B/C/delta; Road original/target centers; eight reduced state scalars |
| Lateral endpoints | A; z0.y/z0.w; T/rho |

Consumed numeric inputs must be real, finite, numeric scalars convertible to
double. Logical, character, cell, complex, empty and nonscalar values are
rejected. A/B/C must be positive, delta nonnegative, target center greater
than original center, and T nonnegative. Scalar values are converted to
double before arithmetic. Unused malformed fields are not inspected.

Malformed inputs use `AVLC:InvalidGlobalPreservationInput` or
`AVLC:InvalidLateralReachabilityInput`. Negative state values are not
malformed inputs. Negative w0 for the lateral theorem and inadmissible rho
use the explicit status semantics above.

Input Inf/NaN is never accepted. No Inf opportunity field is created. NaN
outputs mean unavailable intermediates outside the relevant domain or rho
interval, not inferred impossibility from a singular finite frontier.
For otherwise finite valid inputs whose derived quantities exceed real
finite double arithmetic, the functions fail explicitly with
`AVLC:GlobalPreservationArithmeticFailure` or
`AVLC:LateralReachabilityArithmeticFailure`; they do not silently turn
overflow into set nonmembership. These are arithmetic-range errors, not
physical-domain or malformed-input classifications.

"Exact" describes evaluation of the frozen analytical object without
discretization, control sampling or optimizer approximation. Ordinary MATLAB
double roundoff remains; no symbolic or interval-arithmetic guarantee is
claimed. Equality predicates themselves have no epsilon.

## Non-goals and subsequent stages

There is no M_x_safe membership oracle, GF1 envelope/GF1-PC, ax transcription,
LP/collocation, optimizer, fixed-T search/evaluator, eta/zeta optimization,
margin evaluation, horizon/tauDual, obstruction diagnostic, controller or
Visualization V1. No external dependency or architecture layer is added.

P0.3.2 is separately planned as an **inner feasible-witness numerical
oracle**: a valid verified witness proves feasibility; no witness found
means UNRESOLVED, never certified infeasibility. A future outer infeasibility
certificate can be added independently. This step implements none of them.
Fixed-T reduction and tauDual require additional contracts and cannot be
inferred from current membership or lateral endpoint availability alone.
